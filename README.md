# Laravel Auth API

REST API untuk sistem autentikasi menggunakan Laravel dan MySQL. Project ini mencakup fitur Register, Login menggunakan Email, Login WhatsApp dengan OTP, serta Forgot Password dengan OTP.

## Features
- Register
- Login dengan Email
- Login WhatsApp + OTP
- Forgot Password + OTP
- Authentication & Authorization
- RESTful API
- MySQL Database
- API Testing menggunakan Postman

## Postman Collection
Postman Collection digunakan untuk melakukan testing dan dokumentasi endpoint API pada project ini.
